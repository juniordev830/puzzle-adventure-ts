# Puzzle Adventure TS

A 2D Grid Puzzle and Pathfinding Adventure Game built with TypeScript.

## 🧩 Features

- **Grid System**: Tile map and maze layout algorithms.
- **A* Pathfinding**: Dynamic path calculation for enemy AI.
- **Level Solvability Verifier**: Automated grid path validator.

## 🛠️ Tech Stack

- **Language**: TypeScript
- **Testing**: Jest

## 🚀 How to Run

```bash
npm install
npm test
```
