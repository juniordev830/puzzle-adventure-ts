# Puzzle Adventure TypeScript

Projeto de estudo de lógica para puzzles em grade, algoritmos de caminho e validação de mapas usando TypeScript.

## Tecnologias

- TypeScript
- Jest
- Node.js e npm

## Requisitos

- Node.js e npm
- Dependências instaladas com npm

## Instalação

```bash
npm install
```

## Comandos

```bash
# Executar testes
npm test

# Compilar TypeScript
npm run build
```

## Estrutura

```text
.
├── src/
├── jest.config.js
├── package.json
├── package-lock.json
└── README.md
```

## Áreas de estudo

- Representação de grade e células.
- Busca de caminhos e validação de conectividade.
- Testes automatizados para casos válidos e inválidos.

Consulte os módulos em `src/` para identificar as funcionalidades efetivamente implementadas.
